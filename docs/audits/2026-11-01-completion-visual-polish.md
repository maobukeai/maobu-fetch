# 完成悬浮窗显示优化

本轮按用户截图收敛完成窗口的重复信息。完成保留 180 秒、悬停与操作暂停计时、打开文件与文件夹等行为沿用前一轮实现。

## 显示变化

- 单项展开由 224×118 缩至 224×94；三项为 224×166，六项为 224×274。收起仍为 224×28，底边位置不变。
- 展开后为连贯面板，取消中间重复页脚；标题改为“最近下载”，完成数量只在底条显示一次。
- 完成态只保留一个关闭按钮。单文件行不再重复摆放打开文件/文件夹图标，底条仍能直接操作；多文件时保留逐项快捷操作。
- 文件名前增加简洁文件图标，文件名/大小采用 11px/10px，调整对齐与留白。浅深色分别使用一致的边框和文字层级；折叠状态保留半透明底色。
- 底部打开文件、文件夹、关闭按钮在展开前后使用相同 DOM 和屏幕位置，避免悬停展开后按钮消失或首击误操作。
- 多条文件的三/六项展开控制移至标题栏；主窗口入口保留在标题栏。
- 单文件打开失败时，36px 文件行区域显示安全错误与重试按钮，避免 94px 小窗把文件名和错误互相挤压。底部快捷操作继续可用。
