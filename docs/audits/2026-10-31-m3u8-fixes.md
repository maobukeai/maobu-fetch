# 原生 M3U8 第一批修复与复验记录

日期：2026-10-31（Asia/Shanghai）。对应原审查 M01—M05。本记录只描述本批实际实现和证据，不代表所有媒体站点已经通过完整下载验收。

## 已落实

| 原问题 | 修改 | 生产模块行为证据 |
| --- | --- | --- |
| M01：合并失败仍成功、删除正确分片 | 同目录原子提交；Windows 使用现有 windows-sys 的 MoveFileExW（替换和写穿透），失败保留旧目标、合并文件、分片与恢复清单。合并流逐片重新核验长度及 SHA-256，flush/sync 后再提交 | 只读旧目标保持 `STALE`，正确分片 `CORRECT` 保留且返回 Err；同长度损坏分片无法合并为完成 |
| M02：BYTERANGE 接受 200 或错误偏移 | 必须 206；检查 Content-Range 起点/终点/总长语法、Content-Length、实际接收字节数；200、416、缺失/错误范围明确失败 | 有效两个 Range 得到准确 8 字节及一致 SHA-256；忽略 Range、错位、缺失字段和 416 均拒绝；未知长度普通流可完成，截断流拒绝 |
| M03：未知加密写出密文、密钥错误被掩盖 | 解析阶段拒绝 SAMPLE-AES、未知 METHOD、非 identity KEYFORMAT、无效 KEYFORMATVERSIONS、错误 IV/缺失 URI；包括 Master SESSION-KEY。AES-128 只接受标准 PKCS#7，移除错误填充后退回 NoPadding 的假成功路径 | DRM/非法声明在请求媒体前失败；真实 AES 加密/解密成功，确定错误 IV 的 padding 失败且不产生完成文件 |
| M04：非空缓存即被信任 | 新恢复清单绑定源/最终媒体列表的哈希、媒体序列、Range、加密参数和 MAP；只记录哈希及验证器，不保存凭据或完整签名 URL。缓存必须匹配长度、SHA-256 与远端强 ETag/Last-Modified；旧版无清单缓存重新下载 | `BAD`/同长度 `DAMAGED` 均重下；断点重建后只复用本地哈希和 HEAD 验证器均匹配的分片；ETag 大小写变化、Last-Modified 变化和列表变化均拒绝拼接并保留旧数据 |
| M05：直播首窗口即完成 | 无 ENDLIST 持续刷新，按序列去重并保持初始化段顺序；维护滑动窗口，识别序列重写/缺口。仅明确停录许可才把已完成连续前缀保存并返回 Completed；普通暂停保留恢复数据，取消、删除、退出、超时均不发布 | 三轮滑动列表合并为 `ABC`，每个媒体仅请求一次；未 ENDLIST 时任务保持运行；明确停录保存 `AB`；无许可取消不生成完成文件；无更新达到期限返回错误并保留分片 |

请求响应头及 body 等待均可取消，单次等待最长 30 秒，连接错误采用有界重试；失败 worker 取消其他连接，但不取消外层用户 token，以免真正失败被误当暂停。连接数取实际活动请求，进度只计已校验并持久化的分片，重试网络流量不会重复累加为完成进度。数据库进度更新先读取当前任务，避免旧快照覆盖新的用户设置或复活已删除记录。

原 500 行下载函数拆为任务适配、HTTP 请求、恢复清单、流式合并、直播调度和媒体状态解析模块。没有新增 Cargo 依赖，沿用 reqwest、serde、sha2、Tokio 与现有 windows-sys。媒体缓冲采用整个进程共享的 256 MiB 预算、单分片 128 MiB 上限，分配失败返回明确错误；AES 原地解密，避免密文/明文多份大拷贝。超出支持上限会停止并保留数据，不能声称支持任意大小单个 HLS 分片。

## 集成约定

- `download_m3u8_task` 保持现有参数及 `Result<DownloadTask, String>` 返回类型，不改命令或 `/v1` 协议。
- 任务适配器通过 `manager.live_finalize_permission(id)` 取得代际内部 `Arc<AtomicBool>`；仅明确 `finish-recording` 操作才授予停录保存许可，直播可以成功保存并返回 `TaskStatus::Completed`。普通 `pause` 只暂停并保留恢复数据。
- 点播取消始终返回错误并保留分片；取消、移除、退出、总超时不得授予直播完成许可。
- 下载器先生成并验证任务临时输出，保留分片。manager 必须核验临时/最终文件存在、普通文件、非空且长度准确，再原子发布并清理任务临时目录。也提供 `cleanup_completed_parts(temp)` 供成功发布后的精确清理；不递归删除用户下载目录。
- `REMOTE_CHANGED:` 已由任务适配器落为 RemoteChanged 并保存中文原因，外层不能自动重试拼接旧资源。
- 根任务已协调下载 client 禁用自动 gzip/brotli/deflate 解码，确保 Range 校验看到原始响应语义。
- HLS 专用 client 禁止自动重定向；引擎逐跳处理 301/302/303/307/308，最多 10 跳。相对 Location 按响应地址解析，每跳重做认证头作用域校验；跨源不携带源站平铺 Cookie、Authorization、自定义 API 密钥，Referer 降为来源 origin；同源保留原认证信息。Netscape Cookie jar 保留域/path/secure/过期时间，每个实际请求按目标地址重新生成合法 Cookie 头，不发送原始多行 jar；jar 中本就授权给 CDN 的 Cookie 可以按其作用域发送。GET 与缓存 HEAD 校验均遵守此规则。

最近一次结果：**37 passed / 0 failed / 0 ignored**，其中 6 项原有解析/加密测试、29 项生产传输与文件行为测试、2 项实际 Cookie scope 测试；运行 0.74 秒。真实 302 跳转测试断言 playlist、跳转页和远端媒体各收到与 path 匹配的 Cookie，过期/外域 Cookie 不发送，跨源 Authorization 被剥离。最新两项用例修复 Master 外部音轨静默遗漏：带 URI 的外部 AUDIO 明确拒绝、缺组引用拒绝、无 URI 的合法 in-band 组保留；真实 HTTP 负向只取一次 Master，不请求 video/audio 子列表、不创建无声视频文件。测试只访问 `127.0.0.1` 的随机端口，写入 TempDir 合成文件，没有读取个人 Cookie/数据库，没有下载公网视频。

真实直播识别新增内部原子标记：只有实际解析到无 ENDLIST 的媒体列表才置位，曾直播事实保留到该任务结束；不能靠 URL 含 `.m3u8` 或未知时长猜测。真实直播用例断言标记置位，失败 Master 用例断言标记仍为 false。

后续真实单 Wry `recording-flow` 集成最终 **1/1 通过，6.20 秒**：使用本机 HTTP 服务的实际 2 秒 H.264/AAC TS 源，在应用未配置 yt-dlp/FFmpeg 时，从无 `.m3u8` 后缀的 `/live` 无 ENDLIST 列表识别直播；普通暂停变为 Paused、不发布完成文件、分片 SHA 保持；恢复仍走原生 HLS；只有 `finish-recording` 保存真实 `.ts`，产物经双轨完整解码验证。另覆盖配置工具时实际 MP4、点播 `is_live=false`、伪造点播直播标记拒绝，以及 cancel/remove/shutdown 不发布。新增首段 GET 永不返回 body 的真实负向：显式停录返回可操作错误并原子收尾为 Paused，active=0、无 controls、无完成文件，不留 Downloading 孤儿任务。Store 旧 JSON 兼容、活跃任务原子标记与停止失败收尾 **3/3 通过**。日志为 `TEMP/maobu-recording-final-manager-tests.log`。这些是本地受控集成结果，不能外推长期公网直播。

## 仍需后续验收或扩展

- 真实平台直播长期录制、Windows 休眠/恢复、磁盘满注入、突然断电/进程强杀以及最终目标发布失败的完整 manager 流程，不能由本地字节 fixture 外推为通过。
- 普通暂停、恢复、显式停录及取消/移除/退出的原生 manager 链路已按上述本地场景实测；真实桌面按钮、完成提示及视觉交互检查应另见 UI 专项证据。
- 外部独立音轨的 Master Playlist、字幕 Rendition、LL-HLS 增量/部分分片不是原生已完成能力；外部 AUDIO 现明确报错并引导媒体解析/工具，不能只取 video 假称完整。增量 SKIP 列表也明确拒绝，防止错用媒体序列。
- 原生切片合并不等于 TS→MP4 容器转换。后续媒体发布批次已按实际容器处理，TS 可保留真实 `.ts`，有工具时重封装并验证后发布；相应真实工具/解码证据记录在媒体与 M16 专项中，不能仅凭扩展名或本 HLS 字节探针宣称正确 MP4。

规范依据：AES-128 的 PKCS#7、加密 MAP 的显式 IV、字节范围的隐式偏移以及初始化段作用域均参照 [RFC 8216](https://www.rfc-editor.org/rfc/rfc8216.html)。本批没有实施任何 DRM 绕过。
