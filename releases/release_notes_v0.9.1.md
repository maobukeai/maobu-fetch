# 猫步下载器 (Maobu Fetch) v0.9.1 发布说明

🎉 欢迎使用猫步下载器 **v0.9.1**！本次更新重点为内置硬件加速播放器带来了全新的音量滑块弹出调节交互、优化了看图器的窗口定位与多开体验，并保持浏览器扩展与桌面端的协议全兼容。

---

## 🌟 新增功能与体验升级

### 1. 播放器音量按钮点击弹出高精度调节滑动条
- **全新极晶毛玻璃音量调节面板**：点击底部控制栏 `[ 🔊 ]` 音量按钮即可在正上方弹出精致流畅的音量控制面板，彻底解决此前在小窗口或迷你画中画模式下（`< 520px`）内联滑动条被隐去、用户无法微调音量的问题；
- **0% ~ 200% 高精度宽幅调节**：采用 2% 高细粒度步进，原生支持高动态 Web Audio API 软音量增益放大（超过 100% 自动高亮标识“增益”）；
- **独立静音与快捷档位**：浮动面板内配备独立【静音/恢复】切换按钮，并提供 `静音`、`50%`、`100%`、`200%` 四档常用快捷预设，点击一键直达；
- **高效快捷操控**：
  - 鼠标悬停在音量图标或音量浮窗内滚动滚轮，即刻按 5% 步长快速连续调节；
  - 在音量图标上快速双击可快速静音或取消静音；
  - 键盘 `↑` / `↓` 及 `M` 键保持完全同步联动；
  - 点击播放画面其他区域或按 `Esc` 键平滑收起浮窗，且绝不会误触暂停。

### 2. 看图器窗口定位与预探测尺寸消除闪烁跳动
- **毫秒级物理分辨率预探测**：在 Tauri 窗口创建前微秒级读取图片头部标头数据（原生支持 PNG、JPEG、WebP、GIF、BMP），提前计算契合图片真实比例的最优宽高；
- **一步到位居中呈现**：首张图片打开即绝对居中，无任何位置瞬闪跳动；多图批量打开时平滑智能层叠。

### 3. 浏览器扩展与版本协同
- 浏览器扩展同步升级至 **v0.9.1**，保持协议向前向后平滑兼容。
