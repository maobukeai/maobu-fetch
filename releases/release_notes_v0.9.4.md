# 猫步下载器 (Maobu Fetch) v0.9.4 发布说明

🎉 欢迎使用猫步下载器 **v0.9.4**！本次更新重点引入了 Windows 开机自启后台静默运行（零弹窗不打扰）、启动时自动检测应用更新、全新全局更新弹窗及一键零点击后台静默极速更新。

---

## 🌟 核心升级与新特性

### 1. 开机自启后台静默运行（零弹窗不打扰）
- **真正的后台静默托管**：Windows 开机随系统自启动时（附带 `--autostart` 标志），程序在初始化完成后保持主窗口完全隐藏，直接优雅驻留于系统托盘；
- **消除窗口闪烁跳动**：主窗口默认保持未呈现状态，在确认不是自启模式后才执行主界面呈现，彻底消除开机时主窗口一闪而过的视觉干扰；
- **随时双击唤醒**：用户随时双击系统托盘猫步图标即可平滑呼出主界面。

### 2. 启动时自动检查更新与全局更新弹窗
- **智能开机与启动巡检**：设置页面新增【启动时自动检查应用更新】开关（默认开启），客户端启动后在后台轻量探测新版本；
- **全屏全局更新弹窗**：检测到新版本时自动弹出精致毛玻璃风格更新卡片，清晰呈现新版本号、发布时间及更新日志摘要；
- **实时下载进度可视化**：点击更新后，弹窗内实时动态显示下载进度百分比、已下载大小 / 总大小以及实时下载速率。

### 3. 一键零点击后台极速自动更新
- **全自动静默覆盖**：安装包流式下载完成并通过 SHA-256 完整性校验后，自动调用安装器后台静默安装流程；
- **安全平滑重启**：安装器自动安全关闭旧版进程并替换文件，安装完成后无需任何手动点击即刻自动重新拉起新版猫步下载器，更新体验如丝般顺滑。

### 4. 浏览器扩展与版本协同
- 浏览器扩展与桌面端统一升级至 **v0.9.4**，保持高版本协议平滑向后兼容。
