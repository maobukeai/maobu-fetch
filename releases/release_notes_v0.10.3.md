# 猫步下载器 (Maobu Fetch) v0.10.3 发布说明

🎉 欢迎使用猫步下载器 **v0.10.3**！本版本带来了浏览器端静默无感接管体验升级，全面支持 Windows 重定向系统下载目录权威识别与设置界面便捷交互。

---

## 🌟 核心升级与新特性

### 1. 浏览器扩展原生“另存为”弹窗静默压制
- **异步文件名决策拦截**：新增对 `chrome.downloads.onDeterminingFilename` 的监听与异步挂起机制；
- **彻底消除干扰对话框**：当浏览器开启“下载前询问每个文件的保存位置”设置时，接管期间自动阻止原生文件选择框弹出，待接管桌面端后直接静默取消浏览器下载，提供真正无感接管体验；若判定不接管则安全放行，保障原生下载正常运作。

### 2. Windows 真实/重定向系统下载目录权威解析
- **Win32 原生 KnownFolder 支持**：通过 `SHGetKnownFolderPath` 与 `FOLDERID_Downloads` API，权威获取用户系统真实的“下载”文件夹（包含用户将下载目录更改或重定向至 D 盘/E 盘等场景）；
- **注册表与已知文件夹兜底**：构建健壮的多级解析链路，确保各版本 Windows 系统环境下稳定获取系统默认下载位置。

### 3. 设置界面交互优化与旧版路径自动迁移
- **数据库无缝平滑迁移**：启动时自动检测历史旧版写死的默认 C 盘下载目录，并自动安全迁移至用户的真实系统下载目录；
- **目录选择与重置快捷键**：设置页面“下载保存目录”新增“浏览...”原生文件夹选择按钮与“系统默认”一键恢复系统目录按钮。

### 4. 全量自动化测试与工程质量保障
- 浏览器扩展与前端自动化测试套件扩充至 162 项，100% 绿灯通过；
- Rust 后端单元测试与并发测试套件 1200 项，100% 绿灯通过。

## 🛡️ 安全与合规说明
- 基础安装包（EXE 及 MSI）严格限制在 30 MB 体积预算内；
- 基础安装包零捆绑第三方二进制（按需下载与 SHA-256 完整性校验）；
- 本地跨进程通信严格限制在 127.0.0.1 回环地址并强制 HMAC-SHA256 签名校验；
- 扩展包提供版本化文件与通用命名文件双产物，保证多浏览器平滑自动更新。
