# 猫步下载器 (Maobu Fetch) v0.9.0 发布说明

🎉 欢迎使用猫步下载器 **v0.9.0**！本次更新重点带来了猫步看图器的 Windows 系统文件关联与命令行唤起、任务双击打开行为自定义偏好、系统代理智能识别与远端 DNS 防污染升级（SOCKS5h 自动升级，完美支持 ChatGPT Estuary 等国际站点图片与资源直接下载），以及浏览器扩展的多项媒体嗅探与右键下载增强。

---

## 🌟 新增功能与体验升级

### 1. 猫步看图器与 Windows 系统文件关联
- **Windows 系统规范关联与推荐应用识别**：完整注册 `MaobuFetch.Image` ProgID，补全 Windows 10/11 `RegisteredApplications`（默认应用能力中心）与 `Applications\maobu-fetch.exe\SupportedTypes` 注册表项，使猫步看图器原生出现在 Windows【打开方式】与【建议的应用】推荐列表；
- **多开多窗口独立展示与批量打开**：突破单窗口限制，支持多张图片同时打开独立窗口进行对比查看；支持 Windows 资源管理器中一次多选批量打开；新图片打开时自动提升至前台激活并执行防遮挡智能层叠偏移；若重复打开已打开的同一图片，则精准将该图片所在窗口唤醒并置顶；
- **命令行极速唤起**：实现 `--view-image` 命令行解析与多进程单实例转发机制，无论冷启动还是后台常驻，双击关联图片均能毫秒级打开独立极速看图窗口；
- **一键设置系统默认**：在设置面板中提供【一键注册所有图片关联】与【打开 Windows 默认应用设置】按钮，直达系统面板完成默认看图应用指定。

### 2. 双击任务打开偏好设置
- **自定义双击动作**：在【设置】->【媒体组件与文件关联】中新增“双击任务打开方式”偏好：
  - **内置轻量播放器与看图器（默认）**：直接唤起猫步内置硬件加速播放器或极速看图器；
  - **Windows 系统默认关联程序**：直接调用 Windows 系统的默认应用程序（如系统自带照片、第三方播放器等）。
- **右键菜单双轨并存**：无论默认偏好如何，任务右键菜单均同时提供“打开文件（系统默认）”与“内置播放器/看图器打开”，随心选择。

### 3. 系统代理识别优化与 DNS 防污染保护
- **SOCKS5h 自动升级**：客户端在建立连接前自动将 `socks5://` 规范化为 `socks5h://`，强制由远端代理服务端解析域名，彻底规避境内本地 DNS 污染导致 TLS 连接重置的问题；
- **Windows 注册表优先**：在“跟随系统”模式下优先读取 Windows 注册表真正的 WinINet 系统代理（与 Clash Verge、v2rayN 等代理客户端无缝衔接），无代理时安全回退环境变量。完美解决 ChatGPT 生成图片（Estuary 接口）下载失败的问题。

### 4. 浏览器扩展增强与媒体嗅探体验优化
- **ChatGPT 媒体智能解析**：自动解析 Estuary 图片并赋予直观文件名，同时传递认证与 Referer 信息；
- **右键媒体快速下发**：优化上下文菜单媒体下发链路与离线安全降级机制；
- **扩展版本同步**：浏览器扩展升级至 0.9.0，全面保持协议向前向后兼容。
