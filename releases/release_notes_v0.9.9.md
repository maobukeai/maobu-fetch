# 猫步下载器 (Maobu Fetch) v0.9.9 发布说明

🎉 欢迎使用猫步下载器 **v0.9.9**！本版本正式引入 Windows 原生 MSI 安装包支持，同时由 GitHub Actions 云端流水线全自动构建并发布全套资产。

---

## 🌟 核心升级与新特性

### 1. 新增 Windows 原生 MSI 安装包支持
- **原生 WiX Toolset 构建**：通过 WiX 工具链编译生成标准化 Windows Installer 安装包，原生支持域控与企业批量组策略静默部署；
- **独立稳定 UpgradeCode**：为 MSI 包配置了固定的升级代码 GUID，确保未来版本无缝覆盖升级与卸载回滚；
- **全套双格式安装分发**：现在官方发布页同时提供标准 EXE 安装包（NSIS）与原生 MSI 安装包，满足不同用户群体和企业 IT 管理环境的需求。

### 2. 云端 CI/CD 自动化流水线同步升级
- **多目标构建支持**：GitHub Actions 流水线现已同时编译 NSIS 与 MSI 双目标，并在云端完成全自动化封包与指纹校验；
- **发布资产统一命名**：MSI 包统一命名为 `Maobu.Fetch_{version}_x64.msi`，与 `Maobu.Fetch_{version}_x64-setup.exe` 保持规范一致。

### 3. 严格遵循向后兼容与安全强约束
- **扩展双命名保障**：浏览器扩展包继续同时挂载版本化压缩包与通用命名压缩包，确保历史客户端无缝一键平滑升级；
- **纯净轻量无捆绑**：NSIS 与 MSI 安装包体积均远低于 30 MB 强约束，且不含任何第三方工具二进制文件。

## 🛡️ 安全与合规说明
- 基础安装包（EXE 及 MSI）均远低于 30 MB 强约束；
- 基础安装包内零捆绑第三方可执行程序（严格按需下载与 SHA-256 校验清单）；
- 本地通信严格限制在 127.0.0.1，保留 HMAC-SHA256 签名鉴权；
- 扩展包提供版本化文件与通用命名文件双产物，保证历史客户端一键平滑更新。
