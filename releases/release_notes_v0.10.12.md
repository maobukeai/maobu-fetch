# 猫步下载器 (Maobu Fetch) v0.10.12 发布说明

🎉 欢迎使用猫步下载器 **v0.10.12**！本版本带来了核心 Rust 下载与流媒体架构的**深度模块化解耦重构**、BT 纯 Rust 引擎全面细分子模块治理、网盘通用分页与高可用请求封装、**浏览器扩展文档智能嗅探与局域网互联安全审批机制**，并持续加固**桌面软件自动更新与浏览器扩展自动更新双通道机制**。

---

## 🔄 软件自动更新与浏览器扩展自动更新机制说明

### 1. 桌面软件自动更新（Desktop App Auto-Update）
- **多通道高可用检测探针**：内置三级防失联更新检测链路——优先请求 GitHub Releases REST API；当遇到网络波动或 API 触发 HTTP 403 限流时，自动无缝降级至 Releases Atom 订阅源与 302 重定向探针，确保全天候稳定发现新版本。
- **提醒优先与零后台偷跑**：遵循本地优先原则，软件启动或手动点击“设置 → 关于 → 检查更新”时仅检测并弹窗提醒，绝不静默后台偷跑流量；用户确认升级后，由多线程内核高速拉取新版安装包。
- **强制 SHA-256 完整性校验**：更新包下载完成后，客户端自动比对发布清单中的 64 位 SHA-256 哈希指纹，校验 100% 一致后方可启动安装升级并自动迁移保留全部历史任务、分片与 SQLite 配置。

### 2. 浏览器扩展自动更新（Browser Extension Auto-Update）
- **插件版本同步升级（`v0.10.12`）**：桌面端通过本地安全桥（`127.0.0.1:17433`）实时感知当前已配对 Chrome / Edge 扩展的运行版本号（`0.10.12`），并在检测到版本落后时主动提醒一键更新。
- **双命名资产向后兼容直通**：每次版本发布均同时挂载“版本化扩展压缩包”与“通用扩展压缩包”双资产，确保历史存量客户端与新版客户端无论通过 API 还是静态直链均能 100% 准确拉取最新插件。
- **应用内一键热解压覆盖**：在桌面端点击“更新浏览器扩展”后，系统自动下载最新扩展包、执行 SHA-256 校验与路径穿越防护校验（校验根级 `manifest.json`），并直接解压覆盖至本地扩展目录；用户在浏览器扩展管理页点击刷新即可无感完成升级，原有 HMAC-SHA256 配对令牌与接管规则完全保留。

## 🌟 v0.10.12 核心升级与重构亮点

### 1. 核心下载与媒体流架构深度模块化拆解
- **消除超长代码单体**：彻底重构下载调度管理器、媒体分析提取器、音频/视频混流引擎与多平台适配层，将其拆解为聚焦单一职责的子模块，大幅提升代码可维护性、并发安全与测试覆盖率；
- **BT 引擎子系统治理**：将 BT 纯 Rust 会话管理细化为任务添加、生命周期状态快照、做种策略流控、速率限制器与分片校验等独立模块；
- **网盘通用分页与高韧性请求**：百度网盘、夸克网盘、123 云盘、蓝奏云与 PikPak 统一抽象分页流引擎与请求防护层，降低网络抖动时长尾重试的开销。

### 2. 浏览器扩展文档嗅探与局域网互联安全审批
- **文档与各类资源智能嗅探**：新增专属文档嗅探子系统，智能捕捉页面 PDF、Office 文档及各类打包资源，增强多类型文件的一键接管能力；
- **局域网安全配对审批页**：针对跨设备局域网互联 (LanDisk) 场景新增独立授权审批机制，防止未授权跨源请求，全面保障用户局域网通信安全；
- **Cookie 凭据上下文安全隔离**：严密隔离会话级与请求级认证凭证，提升多账号与受保护资源下载的稳定性。

### 3. 构建发布工程流水线与元数据校验加固
- **严格发布元数据门禁**：打包脚本引入产物修改时间一致性校验、安装包文件名精确正则匹配与 Windows 原生版本资源结构化校验，杜绝旧构建产物混淆误发。

## 🛡️ 安全与合规说明
- 基础安装包（NSIS 与 MSI）体积均严格控制在 30 MB 强约束以内；
- 基础安装包内零捆绑第三方媒体可执行程序（全部遵循用户确认后按需下载与 SHA-256 校验清单）；
- 本地跨进程通信严格绑定 `127.0.0.1` 回环地址，强制执行精确扩展 Origin 校验与 HMAC-SHA256 签名鉴权；
- 扩展发布同时提供版本化与通用命名双产物，全面支持桌面端与浏览器扩展自动更新。
