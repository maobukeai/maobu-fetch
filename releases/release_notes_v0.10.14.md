# 猫步下载器 (Maobu Fetch) v0.10.14 发布说明

🎉 欢迎使用猫步下载器 **v0.10.14**！本版本带来了**小红书、快手与西瓜视频原生探测解析引擎**（支持分享短链自动展开、无水印高清视频与图集原图一键抓取）、媒体选择对话框原片一键兜底选定体验优化，并持续加固**桌面软件自动更新与浏览器扩展自动更新双通道机制**。

---

## 🔄 软件自动更新与浏览器扩展自动更新机制说明

### 1. 桌面软件自动更新（Desktop App Auto-Update）
- **多通道高可用检测探针**：内置三级防失联更新检测链路——优先请求 GitHub Releases REST API；当遇到网络波动或 API 触发 HTTP 403 限流时，自动无缝降级至 Releases Atom 订阅源与 302 重定向探针，确保全天候稳定发现新版本。
- **提醒优先与零后台偷跑**：遵循本地优先原则，软件启动或手动点击“设置 → 关于 → 检查更新”时仅检测并弹窗提醒，绝不静默后台偷跑流量；用户确认升级后，由多线程内核高速拉取新版安装包。
- **强制 SHA-256 完整性校验**：更新包下载完成后，客户端自动比对发布清单中的 64 位 SHA-256 哈希指纹，校验 100% 一致后方可启动安装升级并自动迁移保留全部历史任务、分片与 SQLite 配置。

### 2. 浏览器扩展自动更新（Browser Extension Auto-Update）
- **插件版本同步升级（`v0.10.14`）**：桌面端通过本地安全桥（`127.0.0.1:17433`）实时感知当前已配对 Chrome / Edge 扩展的运行版本号（`0.10.14`），并在检测到版本落后时主动提醒一键更新。
- **双命名资产向后兼容直通**：每次版本发布均同时挂载“版本化扩展压缩包”与“通用扩展压缩包”双资产，确保历史存量客户端与新版客户端无论通过 API 还是静态直链均能 100% 准确拉取最新插件。
- **应用内一键热解压覆盖**：在桌面端点击“更新浏览器扩展”后，系统自动下载最新扩展包、执行 SHA-256 校验与路径穿越防护校验（校验根级 `manifest.json`），并直接解压覆盖至本地扩展目录；用户在浏览器扩展管理页点击刷新即可无感完成升级，原有 HMAC-SHA256 配对令牌与接管规则完全保留。

## 🌟 v0.10.14 核心升级与新特性亮点

### 1. 小红书、快手、西瓜视频原生解析引擎上线
- **全平台分享短链自适应识别**：新增支持 `xhslink.com`、`v.kuaishou.com` 与 `v.ixigua.com` 等常见分享短链接，复制口令文本即可智能提取目标网址并自动重定向解析；
- **小红书图集与无水印短视频提取**：支持图集笔记高清无水印图片批量提取与短视频原片流快速解析；
- **快手与西瓜视频多清晰度流解析**：开箱即用支持多分辨率视频流与纯音频流提取，自动补齐平台认证凭据适配。

### 2. 新建任务媒体格式选择交互优化
- **原片快速一键选定**：针对部分平台提供的原始未转码流或未知音轨视频，在提示信息旁新增“选择此原片”快捷入口，无需繁琐查找即可一键创建下载任务；
- **平台兼容性矩阵同步更新**：设置页中的平台支持列表同步新增小红书、快手与西瓜视频的能力标识。

- 基础安装包（NSIS 与 MSI）体积均严格控制在 30 MB 强约束以内；
- 基础安装包内零捆绑第三方媒体可执行程序（全部遵循用户确认后按需下载与 SHA-256 校验清单）；
