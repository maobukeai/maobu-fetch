# 猫步下载器 (Maobu Fetch) v0.10.0 发布说明

🎉 欢迎使用猫步下载器 **v0.10.0**！本版本带来了多项核心下载引擎优化、交互体验升级以及全自动化构建与发布的持续强化。

---

## 🌟 核心升级与新特性

### 1. 零成本探针与流式响应深度复用
- **防止一次性直链作废**：下载开始阶段直接根据初始探测状态判定 Range 支持情况，避免冗余发起二次 Range 请求导致部分网盘、云存储的一次性限时签名直链失效；
- **单连接流式快速复用**：针对不支持分片 Range 的资源，直接复用已建立的初始探测流无缝衔接下载，降低首字节延迟。

### 2. Windows 文件关联格式细粒度独立控制
- **单格式自由切换**：支持点击单个媒体格式独立注册或注销关联，无需全量绑定；
- **卡片化视觉与交互重构**：设置中心全新上线文件关联卡片与状态徽章，一键打开 Windows 默认应用设置或注销关联。

### 3. HTTP 规范化请求头与 RFC 5987/6266 文件名增强提取
- **请求头规范化**：自动归一化常见 HTTP 头字段大小写，保证与各类服务端的最佳兼容性；
- **文件名深度解析**：增强 `Content-Disposition` 响应头解析，支持 `filename*=` 等 RFC 规范编码，中文及特殊字符文件名不再乱码。

### 4. 浏览器接管扩展持续增强
- **拦截能力优化**：增强下载拦截决策与 Cookie、Referer、User-Agent 上下文完整传递；
- **质量门全绿**：扩展自动化测试用例扩充至 161 项，100% 绿灯通过。

### 5. 双格式安装包云端全自动化构建
- 持续提供标准 EXE 安装包（NSIS）与原生 Windows Installer（MSI），均低于 30 MB，纯净无广告无第三方捆绑。

## 🛡️ 安全与合规说明
- 基础安装包（EXE 及 MSI）均远低于 30 MB 强约束；
- 基础安装包内零捆绑第三方可执行程序（严格按需下载与 SHA-256 校验清单）；
