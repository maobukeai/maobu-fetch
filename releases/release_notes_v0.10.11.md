# 猫步下载器 (Maobu Fetch) v0.10.11 发布说明

🎉 欢迎使用猫步下载器 **v0.10.11**！本版本带来了抖音直连解析 **`__ac_signature` 纯算法本地计算**、**浏览器扩展音视频嗅探全面增强** 以及 **Windows 平台主窗口前台置顶唤醒穿透 (Foreground Lockout Bypass)**，并持续强化**桌面软件自动更新与浏览器扩展自动更新双通道机制**。

---

## 🔄 软件自动更新与浏览器扩展自动更新机制说明

### 1. 桌面软件自动更新（Desktop App Auto-Update）
- **多通道高可用检测探针**：内置三级防失联更新检测链路——优先请求 GitHub Releases REST API；当遇到网络波动或 API 触发 HTTP 403 限流时，自动无缝降级至 Releases Atom 订阅源与 302 重定向探针，确保全天候稳定发现新版本。
- **提醒优先与零后台偷跑**：遵循本地优先原则，软件启动或手动点击“设置 → 关于 → 检查更新”时仅检测并弹窗提醒，绝不静默后台偷跑流量；用户确认升级后，由多线程内核高速拉取新版安装包。
- **强制 SHA-256 完整性校验**：更新包下载完成后，客户端自动比对发布清单中的 64 位 SHA-256 哈希指纹，校验 100% 一致后方可启动安装升级并自动迁移保留全部历史任务、分片与 SQLite 配置。

### 2. 浏览器扩展自动更新（Browser Extension Auto-Update）
- **插件版本同步升级（`v0.10.11`）**：桌面端通过本地安全桥（`127.0.0.1:17433`）实时感知当前已配对 Chrome / Edge 扩展的运行版本号（`0.10.11`），并在检测到版本落后时主动提醒一键更新。
- **双命名资产向后兼容直通**：每次版本发布均同时挂载“版本化扩展压缩包”与“通用扩展压缩包”双资产，确保历史存量客户端与新版客户端无论通过 API 还是静态直链均能 100% 准确拉取最新插件。
- **应用内一键热解压覆盖**：在桌面端点击“更新浏览器扩展”后，系统自动下载最新扩展包、执行 SHA-256 校验与路径穿越防护校验（校验根级 `manifest.json`），并直接解压覆盖至本地扩展目录；用户在浏览器扩展管理页点击刷新即可无感完成升级，原有 HMAC-SHA256 配对令牌与接管规则完全保留。

## 🌟 v0.10.11 核心升级与修复亮点

### 1. 抖音 `__ac_signature` 纯算法本地计算
- **纯位运算原生实现**：算法完全基于 Rust 纯位运算本地模拟 `byted_acrawler` 签名过程，免除任何外部脚本依赖与逆向服务；
- **穿透风控与无水印直链提取**：完美适配抖音最新 Web 端反爬机制，实现秒级高并发无水印短视频详情提取与流媒体下载。

### 2. 浏览器扩展音视频嗅探与媒体选择全面增强
- **智能过滤与深层媒体探测**：扩展端全面升级探测器逻辑，精准提取多平台视频、音频及分段媒体链接，并过滤无效临时流；
- **Netscape Cookie 凭据双向适配**：支持 Netscape 标准格式与标准 HTTP Cookie 头双向无损互转，提升受保护媒体内容的下载成功率。

### 3. Windows 主窗口前台唤醒穿透 (Foreground Lockout Bypass)
- **可靠置顶与焦点唤醒**：针对 Windows 系统对后台进程直接激活窗口的限制，新增专属唤醒逻辑，在单实例命令行传参、快捷协议拉起或点击托盘图标时可靠恢复窗口并置顶聚焦。

### 4. 局域网互联 (LanDisk) 分桶下载调度强化
- **提升并发分桶与重试韧性**：优化分块管理模型与错误恢复策略，保证批量打包下载过程稳定可靠。

## 🛡️ 安全与合规说明
- 基础安装包（NSIS 与 MSI）体积均严格控制在 30 MB 强约束以内；
- 基础安装包内零捆绑第三方媒体可执行程序（全部遵循用户确认后按需下载与 SHA-256 校验清单）；

- 扩展发布同时提供版本化与通用命名双产物，全面支持桌面端与浏览器扩展自动更新。
