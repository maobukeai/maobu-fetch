# 猫步下载器 (Maobu Fetch) v0.10.4 发布说明

🎉 欢迎使用猫步下载器 **v0.10.4**！本版本同步升级了桌面客户端与 Chrome / Edge 浏览器扩展（插件版本号 `0.10.4`），重点强化了**桌面软件自动更新与浏览器扩展自动更新双通道机制**、MV3 扩展三阶段接管恢复看门狗、任务删除确认护栏以及模板认证凭据自动脱敏。

---

## 🔄 软件自动更新与浏览器扩展自动更新机制说明

### 1. 桌面软件自动更新（Desktop App Auto-Update）
- **多通道高可用检测探针**：内置三级防失联更新检测链路——优先请求 GitHub Releases REST API；当遇到网络波动或 API 触发 HTTP 403 限流时，自动无缝降级至 Releases Atom 订阅源与 302 重定向探针，确保全天候稳定发现新版本。
- **提醒优先与零后台偷跑**：遵循本地优先原则，软件启动或手动点击“设置 → 关于 → 检查更新”时仅检测并弹窗提醒，绝不静默后台偷跑流量；用户确认升级后，由多线程内核高速拉取新版安装包。
- **强制 SHA-256 完整性校验**：更新包下载完成后，客户端自动比对发布清单中的 64 位 SHA-256 哈希指纹，校验 100% 一致后方可启动安装升级并自动迁移保留全部历史任务、分片与 SQLite 配置。

### 2. 浏览器扩展自动更新（Browser Extension Auto-Update）
- **插件版本同步升级（`v0.10.4`）**：桌面端通过本地安全桥（`127.0.0.1:17433`）实时感知当前已配对 Chrome / Edge 扩展的运行版本号（`0.10.4`），并在检测到版本落后时主动提醒一键更新。
- **双命名资产向后兼容直通**：每次版本发布均同时挂载“版本化扩展压缩包”与“通用扩展压缩包”双资产，确保历史存量客户端与新版客户端无论通过 API 还是静态直链均能 100% 准确拉取最新插件。
- **应用内一键热解压覆盖**：在桌面端点击“更新浏览器扩展”后，系统自动下载最新扩展包、执行 SHA-256 校验与路径穿越防护校验（校验根级 `manifest.json`），并直接解压覆盖至本地扩展目录；用户在浏览器扩展管理页点击刷新即可无感完成升级，原有 HMAC-SHA256 配对令牌与接管规则完全保留。

## 🌟 v0.10.4 核心升级与新特性

### 1. 浏览器扩展（MV3）三阶段接管看门狗与并发防踩踏
- **三阶段会话状态机**：将 `storage.session` 接管恢复记录升级为 `confirming`（确认中）、`sending`（发送中）、`task-sent`（已送达桌面端）三阶段状态，并引入模块级串行队列锁，彻底消除多任务并发下载时的会话读写覆盖。
- **精准防重复下载恢复**：严格保障恢复记录先于浏览器下载暂停操作落盘；若 Service Worker 在任务已送达桌面端（`task-sent`）后意外休眠或重启，看门狗唤醒后会自动清理并取消浏览器侧残留条目而非误恢复下载，杜绝同一文件重复下载两份。

### 2. 删除确认安全护栏与文件清单预览
- **结构化删除确认弹窗**：所有涉及删除本地磁盘文件或历史记录的单条/批量操作，均统一接入删除确认对话框，明确展示受影响的任务总数、未完成任务提醒及待删文件名清单（文件数不超过上限时逐一列出）。
- **防误触焦点保护**：针对勾选“同时删除本地文件”或清空历史的高危操作，默认将键盘焦点锁定在“取消”按钮，防止回车误触导致磁盘数据丢失。

### 3. 任务模板凭据自动脱敏与临时登录态识别
- **大小写无关登录态徽标**：统一识别 `Cookie`、`Authorization`、`Referer`、`User-Agent` 等临时登录态请求头，在任务详情面板清晰标注登录态来源。
- **持久化模板凭据剥离**：将任务另存为复用模板时，自动剥离 `Cookie`、`Authorization`、`Proxy-Authorization` 等敏感认证头，严防用户私密凭据意外写入持久化配置。

### 4. 下载内核与视图状态稳定性优化
- **连接数档位标准化**：新建与恢复任务时自动将并发连接数收敛规范化至 `1 / 2 / 4 / 8 / 16 / 32` 合法档位，计量网络恢复标记持久化异常不再阻塞下载恢复流程。
- **快捷视图并发回滚保护**：保存或删除自定义快捷过滤视图（QuickView）失败时采用按 ID 函数式精准回滚，避免并发操作互相覆盖。
