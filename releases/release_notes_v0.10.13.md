# 猫步下载器 (Maobu Fetch) v0.10.13 发布说明

🎉 欢迎使用猫步下载器 **v0.10.13**！本版本带来了**迷你下载进度悬浮窗全面升级**（支持正在下载与已完成双标签页切换、完成任务一键打开/直达文件位置与多状态交互）、**抖音服务端渲染 (SSR) 直链提取子系统深度治理**、媒体格式智能甄别过滤优化，并持续加固**桌面软件自动更新与浏览器扩展自动更新双通道机制**。

---

## 🔄 软件自动更新与浏览器扩展自动更新机制说明

### 1. 桌面软件自动更新（Desktop App Auto-Update）
- **多通道高可用检测探针**：内置三级防失联更新检测链路——优先请求 GitHub Releases REST API；当遇到网络波动或 API 触发 HTTP 403 限流时，自动无缝降级至 Releases Atom 订阅源与 302 重定向探针，确保全天候稳定发现新版本。
- **提醒优先与零后台偷跑**：遵循本地优先原则，软件启动或手动点击“设置 → 关于 → 检查更新”时仅检测并弹窗提醒，绝不静默后台偷跑流量；用户确认升级后，由多线程内核高速拉取新版安装包。
- **强制 SHA-256 完整性校验**：更新包下载完成后，客户端自动比对发布清单中的 64 位 SHA-256 哈希指纹，校验 100% 一致后方可启动安装升级并自动迁移保留全部历史任务、分片与 SQLite 配置。

### 2. 浏览器扩展自动更新（Browser Extension Auto-Update）
- **插件版本同步升级（`v0.10.13`）**：桌面端通过本地安全桥（`127.0.0.1:17433`）实时感知当前已配对 Chrome / Edge 扩展的运行版本号（`0.10.13`），并在检测到版本落后时主动提醒一键更新。
- **双命名资产向后兼容直通**：每次版本发布均同时挂载“版本化扩展压缩包”与“通用扩展压缩包”双资产，确保历史存量客户端与新版客户端无论通过 API 还是静态直链均能 100% 准确拉取最新插件。
- **应用内一键热解压覆盖**：在桌面端点击“更新浏览器扩展”后，系统自动下载最新扩展包、执行 SHA-256 校验与路径穿越防护校验（校验根级 `manifest.json`），并直接解压覆盖至本地扩展目录；用户在浏览器扩展管理页点击刷新即可无感完成升级，原有 HMAC-SHA256 配对令牌与接管规则完全保留。

## 🌟 v0.10.13 核心升级与重构亮点

### 1. 迷你下载悬浮窗体验飞跃与已完成任务流
- **双标签页沉浸式管理**：进度悬浮窗新增正在下载（Downloading）与已完成（Completed）双标签页，下载完成自动流转，任务概览与瞬时速度尽在掌控；
- **完成项一键快捷操作**：支持直接打开已完成文件、在系统文件管理器中定位选中目标以及单项清理；
- **Windows 原生悬浮窗交互打磨**：优化悬浮窗边缘吸附、尺寸自适应与拖拽流畅度，支持全自动贴边隐藏与鼠标悬停智能展开。

### 2. 抖音直连与 SSR 直链解析引擎架构解耦
- **独立 SSR 直连子模块**：将抖音网页端服务端渲染解析与分享链提取沉淀为独立的 Rust 模块与扩展前端脚本，提升解析吞吐与稳定性；
- **无水印原画流智能萃取**：穿透复杂签名风控，毫秒级自适应提取高码率无水印原画视频直链。

### 3. 媒体格式甄别与新建任务体验优化
- **智能格式过滤与清晰度推荐**：新建任务对话框对音视频流格式过滤进行精准收敛，杜绝无效音频流混淆；
- **系统集成与通知稳定性增强**：Windows 前台唤醒穿透与托盘联动逻辑加固，任务完成提示更轻盈及时。
