# 猫步下载器 (Maobu Fetch) v0.9.5 发布说明

🎉 欢迎使用猫步下载器 **v0.9.5**！本版本主要用于自动更新链路端到端联调与验证，全面支持从当前版本一键检测新版本、流式下载、SHA-256 完整性强校验、后台静默无感安装以及自动平滑重启。

---

## 🌟 核心特性与体验升级

### 1. 自动更新全流程端到端闭环
- **启动自动检查**：应用启动时在后台静默请求 GitHub 最新发布版本元数据；
- **全屏新版本弹窗**：优雅呈现更新说明、版本号与发布时间；
- **实时下载进度条**：直观展示下载百分比、已下载大小与实时速率；
- **一键极速静默安装与重启**：通过 SHA-256 校验后全自动调用静默安装器参数（`/S /R`），无需用户手动点击，自动关闭旧进程并完成覆盖安装，随后自动拉起新版本。

### 2. 开机自启后台静默运行
- 随系统开机启动时（附带 `--autostart` 标志），主窗口完全保持隐藏，直接驻留于系统托盘；
- 双击托盘图标随时呼出主界面。

### 3. 浏览器扩展与版本协同
- 浏览器扩展同步升级至 **v0.9.5**，保持协议向前向后平滑兼容。
