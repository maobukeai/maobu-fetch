# 猫步下载器 (Maobu Fetch) v0.10.16 发布说明

🎉 欢迎使用猫步下载器 **v0.10.16**！本版本带来**桌面端与浏览器扩展全链路 10 页 Win11 精密视觉与交互重塑**，全面落地**百度网盘浏览器接管链路**与**桌面独立完成提醒窗口**，并持续加固双端自动更新机制。

---

## 🔄 软件自动更新与浏览器扩展自动更新机制说明

### 1. 桌面软件自动更新（Desktop App Auto-Update）
- **多通道高可用检测探针**：内置三级防失联更新检测链路——优先请求 GitHub Releases REST API；当遇到网络波动或 API 触发 HTTP 403 限流时，自动无缝降级至 Releases Atom 订阅源与 302 重定向探针，确保全天候稳定发现新版本。
- **提醒优先与零后台偷跑**：遵循本地优先原则，软件启动或手动点击“设置 → 关于 → 检查更新”时仅检测并弹窗提醒，绝不静默后台偷跑流量；用户确认升级后，由多线程内核高速拉取新版安装包。
- **强制 SHA-256 完整性校验**：更新包下载完成后，客户端自动比对发布清单中的 64 位 SHA-256 哈希指纹，校验 100% 一致后方可启动安装升级并自动迁移保留全部历史任务、分片与 SQLite 配置。

### 2. 浏览器扩展自动更新（Browser Extension Auto-Update）
- **插件版本同步升级（`v0.10.16`）**：桌面端通过本地安全桥（`127.0.0.1:17433`）实时感知当前已配对 Chrome / Edge 扩展的运行版本号（`0.10.16`），并在检测到版本落后时主动提醒一键更新。
- **双命名资产向后兼容直通**：每次版本发布均同时挂载“版本化扩展压缩包”与“通用扩展压缩包”双资产，确保历史存量客户端与新版客户端无论通过 API 还是静态直链均能 100% 准确拉取最新插件。
- **应用内一键热解压覆盖**：在桌面端点击“更新浏览器扩展”后，系统自动下载最新扩展压缩包、执行 SHA-256 校验与路径穿越防护校验（校验根级 `manifest.json`），并直接解压覆盖至本地扩展目录；用户在浏览器扩展管理页点击刷新即可无感完成升级，原有 HMAC-SHA256 配对令牌与接管规则完全保留。

## 🌟 v0.10.16 核心升级与新特性亮点

### 1. 全链路 10 页 Win11 精密界面与交互重塑
- **主工作区与详情抽屉**：统一 Win11 精密视觉规范，引入导航实时速率微图、全局磁吸切换器与 0px 表格重排滑出式详情抽屉（隔离绘制，杜绝文字穿底）。
- **新建任务与全局弹窗修复**：新建任务弹窗支持结构化分区与触发源 Origin 弹出动效；弹窗与快捷菜单统一迁至顶层渲染层并修复双层磨砂叠压失真问题，彻底还原原生亚克力雾面质感。
- **设置页与历史筛选栏**：设置页重构为紧凑分组工作台；历史筛选新增条件摘要条，高密度下状态一目了然。
- **内置影院播放器与猫步看图器**：播放器升级为无霓虹光晕的影院浮岛控制条，精确修复鼠标悬停与拖拽进度寻址并统一 `MM:SS` 跳过时间显示；看图器改为中性暗石墨画布，修复指针焦点锚定滚轮缩放并消除胶卷与工具栏遮挡。
- **独立进度浮窗与桌面完成提醒**：强化复杂桌面壁纸下的紧凑进度条描边与可读性；完成提示统一启用语义绿标识并新增悬停可暂停的底部 2px 自动关闭倒计时细条。
- **浏览器扩展 4 页同源焕新**：主弹窗、接管规则页、批量链接提取页与网盘打包授权页全套统一 Win11 精密设计令牌，修复单行 4 键站点操作适配并新增状态指示灯呼吸脉冲动效。

### 2. 百度网盘浏览器接管与桌面完成提醒窗
- **百度网盘原生接管链路**：支持通过已配对扩展校验页面身份并安全转交桌面端高并发下载，遇到失效或异常时安全回退浏览器原生下载。
- **桌面独立完成提醒窗口**：支持多条完成提醒排队推进、打开文件 / 打开文件夹 / 查看详情快捷直达及实时自动关闭倒计时控制。
