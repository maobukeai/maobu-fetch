# 猫步下载器 (Maobu Fetch) v0.10.6 发布说明

🎉 欢迎使用猫步下载器 **v0.10.6**！本版本带来了局域网互联2（LanDisk）的全方位端到端原生集成（含桌面端文件选择器与浏览器扩展注入拦截）、批量下载操作汇总工具栏、BT/磁力内核优化，并持续强化了**桌面软件自动更新与浏览器扩展自动更新双通道机制**。

---

## 🔄 软件自动更新与浏览器扩展自动更新机制说明

### 1. 桌面软件自动更新（Desktop App Auto-Update）
- **多通道高可用检测探针**：内置三级防失联更新检测链路——优先请求 GitHub Releases REST API；当遇到网络波动或 API 触发 HTTP 403 限流时，自动无缝降级至 Releases Atom 订阅源与 302 重定向探针，确保全天候稳定发现新版本。
- **提醒优先与零后台偷跑**：遵循本地优先原则，软件启动或手动点击“设置 → 关于 → 检查更新”时仅检测并弹窗提醒，绝不静默后台偷跑流量；用户确认升级后，由多线程内核高速拉取新版安装包。
- **强制 SHA-256 完整性校验**：更新包下载完成后，客户端自动比对发布清单中的 64 位 SHA-256 哈希指纹，校验 100% 一致后方可启动安装升级并自动迁移保留全部历史任务、分片与 SQLite 配置。

### 2. 浏览器扩展自动更新（Browser Extension Auto-Update）
- **插件版本同步升级（`v0.10.6`）**：桌面端通过本地安全桥（`127.0.0.1:17433`）实时感知当前已配对 Chrome / Edge 扩展的运行版本号（`0.10.6`），并在检测到版本落后时主动提醒一键更新。
- **双命名资产向后兼容直通**：每次版本发布均同时挂载“版本化扩展压缩包”与“通用扩展压缩包”双资产，确保历史存量客户端与新版客户端无论通过 API 还是静态直链均能 100% 准确拉取最新插件。
- **应用内一键热解压覆盖**：在桌面端点击“更新浏览器扩展”后，系统自动下载最新扩展包、执行 SHA-256 校验与路径穿越防护校验（校验根级 `manifest.json`），并直接解压覆盖至本地扩展目录；用户在浏览器扩展管理页点击刷新即可无感完成升级，原有 HMAC-SHA256 配对令牌与接管规则完全保留。

## 🌟 v0.10.6 核心升级与新特性

### 1. 局域网互联2（LanDisk）全链路原生接入
- **桌面端交互选单（LanDiskPicker）**：在新建任务弹窗中新增局域网互联2直连选择器，直接浏览并多选远端目录与文件，一键创建批量高速拉取任务。
- **浏览器扩展深度注入拦截**：新增页面注入模块与专用适配器，在浏览局域网互联2网页端时自动注入快捷拉取挂钩，支持一键无缝唤醒猫步下载器进行高速传输。
- **Rust 后端协议与直链解析**：后端新增专用协议解析模块，原生支持 LanDisk 会话令牌认证与免二次重定向的极速流式分块拉取。

### 2. 批量任务操作汇总栏（BatchSummaryBar）
- **全新底部批量管理浮条**：在多选或按类别批量选择任务时，实时展示选中任务总数、总体积、当前总吞吐与预计完成时间。
- **一键批量调度**：支持批量暂停、批量开始、设置并发限速以及批量归档清理，大幅提升大量文件下载场景的操作效率。

### 3. BT / 磁力下载内核与做种策略稳健性强化
- **会话持久化与崩溃恢复**：优化 librqbit 纯 Rust 内核会话的 fastresume 快照保存逻辑，任务重开或异常退出后 100% 无缝续传。
- **做种与限速精准同步**：进一步强化做种完成停止策略，确保全局/单任务令牌桶速率限制与 BT 会话实时同步，杜绝突发抢占带宽。
