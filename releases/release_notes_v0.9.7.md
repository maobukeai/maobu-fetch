# 猫步下载器 (Maobu Fetch) v0.9.7 发布说明

🎉 欢迎使用猫步下载器 **v0.9.7**！本版本正式启用 GitHub Actions 云端流水线全自动构建与发布，固化了标准版本升级与发布流程。

---

## 🌟 核心升级与新特性

### 1. 接入 GitHub Actions 云端全自动流水线
- **纯净云端环境自动打包**：集成 `.github/workflows/release.yml`，在微软云 Windows 虚拟机纯净环境下自动执行全量测试、前端构建与 Rust 桌面端编译；
- **免人工干扰的资产封装**：通过 Node.js 原生打包脚本 `scripts/package-release.mjs` 自动生成 NSIS 基础安装包、便携版可执行程序与符合向后兼容双命名规范的浏览器扩展 ZIP 包；
- **云端动态 SHA-256 签名**：流水线每次自动对生成的二进制产物计算 64 位 SHA-256 物理指纹，并实时注入发布说明。

### 2. 标准化一键版本升级流程
- **固化版本同步命令**：引入 `pnpm run version:bump <版本号>`（对应 `scripts/bump-version.mjs`），实现 `package.json`、`Cargo.toml`、`tauri.conf.json`、扩展配置与 UI 的原子化同步，杜绝版本号漏改。

### 3. 开机后台自启与极速自动更新闭环验证
- 进一步优化了开机静默启动逻辑与一键自动更新的平滑过渡体验。

## 🛡️ 安全与合规说明
- 基础安装包仅 ~4.7 MB（远低于 30 MB 强约束）；
- 基础安装包内零捆绑第三方可执行程序（严格按需下载与 SHA-256 校验清单）；
- 本地通信严格限制在 127.0.0.1，保留 HMAC-SHA256 签名鉴权；
- 扩展包提供版本化文件与通用命名文件双产物，保证历史客户端一键平滑更新。
