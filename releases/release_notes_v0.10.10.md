# 猫步下载器 (Maobu Fetch) v0.10.10 发布说明

🎉 欢迎使用猫步下载器 **v0.10.10**！本版本深度加固了多线程 HTTP 内核与局域网互联 (LanDisk) 批量分桶下载引擎的**并发子令牌隔离、单分桶内建指数退避重试与真实物理续传水位线校准**，彻底解决网络波动时误触发暂停状态的顽疾，并持续强化**桌面软件自动更新与浏览器扩展自动更新双通道机制**。

---

## 🔄 软件自动更新与浏览器扩展自动更新机制说明

### 1. 桌面软件自动更新（Desktop App Auto-Update）
- **多通道高可用检测探针**：内置三级防失联更新检测链路——优先请求 GitHub Releases REST API；当遇到网络波动或 API 触发 HTTP 403 限流时，自动无缝降级至 Releases Atom 订阅源与 302 重定向探针，确保全天候稳定发现新版本。
- **提醒优先与零后台偷跑**：遵循本地优先原则，软件启动或手动点击“设置 → 关于 → 检查更新”时仅检测并弹窗提醒，绝不静默后台偷跑流量；用户确认升级后，由多线程内核高速拉取新版安装包。
- **强制 SHA-256 完整性校验**：更新包下载完成后，客户端自动比对发布清单中的 64 位 SHA-256 哈希指纹，校验 100% 一致后方可启动安装升级并自动迁移保留全部历史任务、分片与 SQLite 配置。

### 2. 浏览器扩展自动更新（Browser Extension Auto-Update）
- **插件版本同步升级（`v0.10.10`）**：桌面端通过本地安全桥（`127.0.0.1:17433`）实时感知当前已配对 Chrome / Edge 扩展的运行版本号（`0.10.10`），并在检测到版本落后时主动提醒一键更新。
- **双命名资产向后兼容直通**：每次版本发布均同时挂载“版本化扩展压缩包”与“通用扩展压缩包”双资产，确保历史存量客户端与新版客户端无论通过 API 还是静态直链均能 100% 准确拉取最新插件。
- **应用内一键热解压覆盖**：在桌面端点击“更新浏览器扩展”后，系统自动下载最新扩展包、执行 SHA-256 校验与路径穿越防护校验（校验根级 `manifest.json`），并直接解压覆盖至本地扩展目录；用户在浏览器扩展管理页点击刷新即可无感完成升级，原有 HMAC-SHA256 配对令牌与接管规则完全保留。

## 🌟 v0.10.10 核心升级与修复亮点

### 1. 并发子令牌隔离（`child_token`）防暂停状态误判
- **用户暂停与网络异常严格解耦**：在多线程 HTTP 下载与局域网互联并发分桶下载中，为内部工作协程引入独立的协调子令牌（`child_token`）。当任一连接因瞬时网络抖动报错时，仅取消子令牌协调其余协程安全落盘并进入自动续传流程，绝不污染外层用户暂停父令牌，彻底修复因网络波动被外层调度器误判为“用户主动暂停”而停止自动重试的问题。

### 2. 超大规模目录分桶并发与内建退避重试加固
- **修复分桶计数截断溢出**：修复当超大规模目录展开的待下载分桶数量恰好为 256 的整数倍（如 256、512、4608 等）时，无符号 8 位整数类型转换截断导致活跃连接数归零的边界问题，采用安全边界钳制确保始终满血并发。
- **单分桶 4 级指数退避与归档完整性校验**：每个分桶内置最多 4 次指数退避自动重试（500ms 至 3000ms）；流读取中途异常时先强制刷盘已接收字节，且对子批次归档分桶执行中央目录结构完整性校验，自动剔除残缺分桶并无缝重拉。

### 3. 真实物理落盘水位线校准
- **零进度倒退**：任务启动、暂停恢复与断点续传时，严格依据磁盘上真实已落盘的原始分片与已验证归档分桶计算初始字节水位线，消除历史虚高进度导致的百分比回退与跳变。
